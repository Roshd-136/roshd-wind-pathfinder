# Roshd Wind Pathfinder — پروژه رشد

پایپلاین پیشپردازش دادههای باد و مسیریابی — پروژه دانشگاهی/تحقیقاتی با تیم فارسیزبان.

## مراحل پروژه

| گام | موضوع | وضعیت |
|-----|-------|--------|
| گام ۱ | منابع داده و کلیدهای API | انجام شد |
| گام ۲ | پیشپردازش و درونیابی (IDW، Kriging، کنترل کیفیت) | در حال انجام |
| گام ۳+ | مسیریابی | آینده |

## همکاری

- **اگر AI agent هستید:** حتماً ابتدا [AGENTS.md](AGENTS.md) را کامل بخوانید — این فایل خودکار در کانتکست شما بارگذاری میشود و قوانین الزامی را مشخص میکند.
- **اگر انسان هستید (همکار):** راهنمای گامبهگام در [CONTRIBUTING.md](CONTRIBUTING.md) است.

## قوانین اصلی (خلاصه)

1. هرگز مستقیم روی `main` کار نکنید — همیشه برنچ بسازید و از طریق Pull Request ادغام کنید.
2. هر PR باید تستها (`pytest`) و لینتر (`ruff`) را پاس کند — CI خودش این را چک میکند.
3. هیچ رازی (توکن/کلید API) در کد یا مستندات قرار نمیگیرد.
4. ادغام نهایی فقط توسط مالک پروژه انجام میشود.

## نصب و توسعه

```bash
python -m pip install -e ".[dev]"
ruff check .      # لینتر
pytest -q         # تستها
```
