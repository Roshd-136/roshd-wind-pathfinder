# Frontend (WindPath)

اسکلت React + TypeScript + Vite مطابق `docs/frontend/architecture.md`.

## اجرا
```bash
npm install
npm run dev        # dev server
npm run build      # build تولید
npm run lint       # eslint
npm run typecheck  # tsc
npm test           # vitest
```

قرارداد API مصرفی: `../api/openapi.yaml`.
