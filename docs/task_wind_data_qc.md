# مستندات کنترل کیفیت داده‌های باد (Wind Data QC)

## هدف (Purpose)
این ماژول وظیفه پالایش و شناسایی داده‌های پرت و نامعتبر از سنسورهای هواشناسی را بر عهده دارد.

## معیارهای کنترل کیفیت (QC Rules)
۱. **اعتبارسنجی بازه (Range Check):** سرعت بين 0 تا 75 m/s و جهت بین 0 تا 360 درجه.
۲. **پیوستگی زمانی (Temporal Consistency):** شناسایی پرش‌های بالای 15 m/s و فریز سنسور.
۳. **همخوانی مکانی (Spatial Consistency):** انحراف بیش از 2.5 برابر STD همسایگان.
