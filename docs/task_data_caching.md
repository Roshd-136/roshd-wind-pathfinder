## خلاصه پیادهسازی

ماژول `WindDataCache` در مسیر `src/data/cache.py` پیادهسازی شده است که وظایف زیر را انجام میدهد:

1. **پایگاه داده محلی SQLite** برای ذخیرهسازی دادههای باد
2. **استراتژی کش** با مدیریت TTL (زمان انقضا)
3. **ساختار ذخیرهسازی** بهینه برای دادههای باد (مختصات + مؤلفههای u/v)
4. **بهینهسازی حجم** با حذف خودکار دادههای منقضیشده

## مثال استفاده

```python
from data.cache import WindDataCache

# Initialize cache
cache = WindDataCache()

# Store wind data
cache.store_wind_data(
    lat=35.7, lon=51.4, altitude=1000,
    timestamp=int(time.time()),
    u_component=5.0, v_component=2.0
)

# Retrieve wind data
wind = cache.get_wind_data(35.7, 51.4, 1000, int(time.time()))
print(f"Wind components: {wind}")  # (5.0, 2.0)

# Get cache statistics
stats = cache.get_cache_stats()
print(f"Cache stats: {stats}")
```

## نکات فنی

- **پایگاه داده:** SQLite — مناسب برای ذخیرهسازی محلی، بدون نیاز به سرور، و با پشتیبانی از تراکنشها.
- **TTL پیشفرض:** ۶ ساعت (۲۱۶۰۰ ثانیه) — قابل تنظیم با `cache._set_ttl("wind", new_ttl)`
- **ساختار داده:** هر رکورد شامل مختصات (lat, lon, altitude)، زمان (timestamp)، مؤلفههای باد (u, v)، و TTL است.
- **بهینهسازی:** استفاده از کلید اصلی ترکیبی `(lat, lon, altitude, timestamp)` برای جلوگیری از ذخیره دادههای تکراری.

---

## بهبودهای آینده

1. **کش چندلایه:** افزودن کش در حافظه (memory cache) برای دادههای پراستفاده
2. **فشردهسازی داده:** ذخیرهسازی دادهها بهصورت فشرده برای کاهش حجم
3. **پشتیبانگیری خودکار:** پشتیبانگیری دورهای از پایگاه داده
4. **مدیریت حافظه:** محدود کردن حجم کش با سیاست LRU (Least Recently Used)
