# دفترچه روند پروژه (PROJECT PROGRESS)

> این فایل دفترچه کار پروژه است. هر ایجنت AI بعد از تمام کردن تسکش، یک **بخش جدید** اینجا اضافه میکند (طبق قالب انتهای فایل).
> **قانون:** بخشهای قبلی را دست نزن، تغییر نده، حذف نکن. فقط بخش جدید **اضافه** کن. اگر چیزی از گذشته غلط از آب درآمد، در بخش خودت «⚠️ اصلاحیه بر بخش X» بنویس.
> **قانون:** قبل از شروع هر تسک، این فایل را بخوان تا بفهمی پروژه الان کجاست و چه خروجی‌هایی از قبل داری.

## تسک: کنترل کیفیت دادههای باد (Wind Data Quality Control) — گام ۲ (مهدی)
- **وضعیت:** ⚠️ ناقص — کد روی main هست (commit `ec458a1`) ولی **بدون PR رفت** و **داده واقعی Open-Meteo را استفاده نکرده** و **تست ندارد**. نیاز به اصلاح دارد:
  1. از Open-Meteo داده fetch کند (طبق تسک API Keys)
  2. تست در `tests/qc/` بنویسد
  3. هرگز مستقیم روی main push نکند
- **چه ساخته:** `src/roshd_wind_pathfinder/qc/wind_qc.py` (کلاس `WindQualityControl` با `QCConfig`) + `docs/wind_qc.md`
- **خروجی فعلی:** ورودی: DataFrame تخت با ستونهای `time, lat, lon` و (`u, v` یا `speed, direction`). خروجی: `(clean_df, report)` — داده پاکسازی‌شده + گزارش خطا. معیارها: NaN، بازه فیزیکی [0,120] m/s، داده پرت (Z-score/IQR/MAD)، پیوستگی زمانی، همخوانی مکانی.
- **برای تسک بعدی (DataPrep / آمادهسازی ورودی مسیریابی):** قبل از ورود به درونیابی/مسیریابی، داده را با `WindQualityControl.run(df)` پاک کن و از `clean_df` استفاده کن.
