# مستندات آماده‌سازی داده ورودی مسیریابی (Data Prep for Pathfinding)

## هدف
تبدیل داده‌های اولیه هواشناسی به گرید منظم سه بعدی (طول، عرض، ارتفاع) و محاسبه بردارهای باد جهت استفاده در الگوریتم مسیریابی.

## ورودی و خروجی
- **واحدها:** سرعت باد بر حسب m/s و جهت بر حسب درجه.
- **بردارهای باد:** محاسبه مؤلفه‌های $U$ و $V$.
- **ارتفاعات:** ۵۰۰، ۱۰۰۰، ۱۵۰۰ و ۲۰۰۰ متر.
- **نرمال‌سازی:** مقادیر بردارها جهت ورودی الگوریتم بین ۰ و ۱ نرمال می‌شوند.
