## دستور برای AI agent

تو یک ایجنت برنامه‌نویس هستی. ریپو را کلون کن و کار را شروع کن. قوانین:

1. **قبل از هر کاری، `AGENTS.md` را کامل بخوان و پیروی کن.** اگر مشکلی در آن دیدی، یک PR جداگانه با پیشنهاد اصلاح بده.

2. **`docs/PROJECT_PROGRESS.md` را بخوان** تا بفهمی پروژه الان کجاست. باید بدانی چه تسکهایی انجام شده، خروجی هر کدام چیست، و تسک تو چه پیشنیازهایی دارد.

3. **اگر تسک را به‌عنوان فایل دریافت نکردی، از کاربر بپرس** — بگو: «لطفاً تسک ClickUp را به‌صورت PDF آپلود کن یا آدرسش را بده.»

4. **از خروجی تسکهای قبلی واقعاً استفاده کن.** اگر تسک تو به داده نیاز دارد، آن را از ماژول `cache` یا از API واقعی بگیر — نه داده ساختگی تولید کن.

5. **اگر جایی شک داری، بپرس.** بهترین کار این است که اول سؤالت را بپرسی و بعد شروع به کدنویسی کنی.

6. **تست بنویس و سبز کن:** `pytest -q` و `ruff check .` باید بدون خطا باشند. اگر قرمز بود، درستش کن.

7. **در آخر، `docs/PROJECT_PROGRESS.md` را آپدیت کن:** یک بخش جدید **اضافه** کن (بخشهای قبلی را دست نزن). بنویس چه ساختی، خروجی چیست و تسک بعدی چه چیزی از تسک تو لازم دارد.

8. **PR بده و merge نکن.** ادغام فقط توسط آرمان انجام میشود.
